# 청년 정책 API 명세

> 담당: 권세진 · 명세 상태: 초안 · 개발 상태: 실제 기능 (저장한 정책)
> 공통 규칙은 `docs/API_RULES.md`를 따른다 (camelCase · 원 단위 정수 · UUID · 세션 쿠키 + CSRF · 에러 모양)

청년 정책 추천은 채팅(`docs/api/chat.md`, 정책 담당)으로 한다. 이 문서는 추천받은 정책을 저장(북마크)하는 API 다.
마이페이지에서 어떻게 보여 줄지는 아직 정하지 않았다.

**주소 속 정책번호**: 정책은 온통청년 공식 정책번호(20자리 숫자 문자열)가 ID 라서 UUID 가 아니다 (`policy` 표의 예외, `docs/DB_MODELS.md`).
없는 번호 · 형식이 틀린 번호는 404 다.

---

## 저장한 정책 목록

| 칸 | 내용 |
|---|---|
| 어떤 기능 | 저장한 정책을 최신순으로 볼 때 (마이페이지 — 화면 미정) |
| 어디로 | `GET /api/policies/saved/` |
| 로그인 필요 | O |
| 명세 상태 | 초안 |

**받는 값 (200)**

| 이름 | 타입 | 뜻 |
|---|---|---|
| `items[].savedPolicyId` | UUID | 저장 한 건의 ID |
| `items[].policyNo` | 문자 | 정책번호 |
| `items[].name` | 문자 | 정책명 (DB 값 그대로) |
| `items[].applyState` | 문자 | `open` 신청 중 · `always` 상시 · `upcoming` 신청 예정 · `unknown` 기간 확인 필요 · `closed` 마감 |
| `items[].applyEnd` | 날짜 \| null | 마지막 신청 마감일. 상시 · 기간 모름이면 `null` |
| `items[].link` | 문자 \| null | 신청 주소, 없으면 참고 주소, 둘 다 없으면 `null` |
| `items[].active` | 참/거짓 | 정책 수집에서 사라졌으면 `false` (저장 기록은 남는다) |
| `items[].savedAt` | 시각 | 저장한 시각 |

```json
{
  "items": [
    {
      "savedPolicyId": "3f2c9a10-…",
      "policyNo": "20261021005400214208",
      "name": "2026 청년 월세 지원",
      "applyState": "open",
      "applyEnd": "2026-12-31",
      "link": "https://…",
      "active": true,
      "savedAt": "2026-11-10T15:30:00+09:00"
    }
  ]
}
```

- 마감 · 수집 종료된 정책도 지우지 않고 상태로 보여 준다. 화면에서 어떻게 표시할지는 마이페이지를 정할 때 정한다.

## 정책 저장

| 칸 | 내용 |
|---|---|
| 어떤 기능 | 추천받은 정책이 마음에 들어 저장할 때 (정책 카드 화면 — 미정. 채팅에서는 [N번 저장] 버튼이 같은 일을 한다) |
| 어디로 | `PUT /api/policies/<policyNo>/saved/` |
| 로그인 필요 | O |
| 명세 상태 | 초안 |

**보내는 값**: 없음 (본문을 보낸다면 `{}` 만. 다른 칸이 있으면 400 `invalid`)

**받는 값 (200)**: 위 목록의 한 칸과 같은 모양

- **이미 저장한 정책이어도 200** 으로 같은 칸을 돌려준다 (두 번 눌러도 한 줄). 그래서 요청 번호(`Idempotency-Key`)가 필요 없다.

**실패하면**

| 상황 | 상태 | `code` | 화면 안내 |
|---|---|---|---|
| 없는 정책번호 · 수집이 끝난(비활성) 정책 | 404 | `not_found` | "찾을 수 없어요" |
| 본문에 칸을 보냄 | 400 | `invalid` | 개발 중 버그 |

## 정책 저장 취소

| 칸 | 내용 |
|---|---|
| 어떤 기능 | 저장한 정책을 목록에서 뺄 때 |
| 어디로 | `DELETE /api/policies/<policyNo>/saved/` |
| 로그인 필요 | O |
| 명세 상태 | 초안 |

**받는 값 (204)**: 본문 없음

- **저장돼 있지 않아도 204** (이미 원하는 상태). 수집이 끝난 정책도 취소할 수 있다.

**실패하면**

| 상황 | 상태 | `code` | 화면 안내 |
|---|---|---|---|
| 없는 정책번호 | 404 | `not_found` | "찾을 수 없어요" |

**확인 필요**

- 마이페이지에서 저장 목록을 어디에 · 어떻게 보여 줄지 (마감 · 비활성 정책 표시 포함) → 팀 회의
- OpenAPI(`docs/openapi/parts/`) 명세 추가 → 화면이 정해지면
