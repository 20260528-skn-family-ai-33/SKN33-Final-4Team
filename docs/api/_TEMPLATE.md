## 로그인

| 칸 | 내용 |
|---|---|
| 어떤 기능 | 로그인 화면에서 이메일·비밀번호를 넣고 [로그인]을 누를 때 |
| 어디로 | `POST /api/auth/login/` |
| 로그인 필요 | X |
| 명세 상태 | 초안 |

**보내는 값**

| 이름 | 타입 | 필수 | 범위·설명 | 예시 |
|---|---|---|---|---|
| `email` | 문자 | O | 이메일 형식 | `"naeun@example.com"` |
| `password` | 문자 | O | 8자 이상 | `"********"` |

```json
{ "email": "naeun@example.com", "password": "********" }
```

**받는 값 (200)** — 로그인 세션 쿠키가 함께 심어진다

| 이름 | 타입 | 뜻 |
|---|---|---|
| `userId` | UUID | 회원 번호 |
| `email` | 문자 | 이메일 |
| `nickname` | 문자 | 화면에 보일 이름 |

```json
{ "userId": "3f2c9a10-…", "email": "naeun@example.com", "nickname": "나은" }
```

**실패하면**

| 상황 | 상태 | `code` | 화면 안내 |
|---|---|---|---|
| 칸이 비었거나 형식이 틀림 | 400 | `invalid` | 칸 아래에 `fields` 메시지 |
| 이메일·비밀번호가 안 맞음 | 400 | `invalid` | "이메일 또는 비밀번호를 확인해 주세요." |

**확인 필요**

- 로그인 뒤 갈 화면(온보딩 진행 단계)은 예산 ML 후 정함 → 김나은과 확인
- 비밀번호 틀린 횟수 제한 여부 → 팀 회의
