## 1. 분류 원칙

- **가게(업종) 기준**으로 분류합니다. 결제가 일어난 가게의 업종으로 카테고리를 정합니다. (10/20 팀 결정)
- 여러 품목을 파는 가게(편의점·마트·종합몰 등)는 상호만으로 품목을 알 수 없으므로 **미분류 → 사용자 선택**으로 처리합니다.
- **고정지출도 일반 카테고리로 분류합니다.** 월세·관리비·공과금·통신요금 → 주거·통신, OTT·음악 구독 → 문화·여가. 고정지출인지는 카테고리와 별도로 표시합니다('고정비' 카테고리는 없음).
- 예산(생활비) 계산에서는 고정비(월세·수도·관리비·연료비·통신요금)를 뺍니다(10/22). 앱 예산이 '월급 − 고정비 − 저축' 뒤 남은 돈을 나누기 때문입니다. 소비 분석에는 고정비도 들어갑니다.
- 예산 모델 데이터(가계동향조사)는 "무엇을 샀나(품목)" 기준이라 일부 업종에서 차이가 있습니다. 이 차이는 4장에 한계로 기록합니다.

## 4. 가계동향조사(예산 모델)와의 차이 — 한계

가계동향 공공용 자료는 중분류까지만 제공되어, 중분류 안에 섞인 항목은 따로 옮길 수 없습니다. 묶음은 금액이 큰 쪽 카테고리에 배정했습니다.

| 가계동향 중분류 | 배정 카테고리 | 앱 기준과 다른 부분 |
|---|---|---|
| 외래의료서비스(보건) | 의료·건강 | 없음 (10/20 성형외과 = 의료·건강으로 일치) |
| 이미용서비스 | 뷰티·미용 | 목욕료(앱: 문화·여가). 마사지·안마는 설계서에 명시 없음, 이 항목으로 추정 |
| 기타개인교통서비스 | 교통·차량 | 운전교습비(앱: 교육) |
| 문화서비스(오락문화) | 문화·여가 | 독서실·문화강습(앱: 교육) |
| 숙박비 | 여행·숙박 | 고시원(앱: 주거·통신) — 여행·숙박 비율이 약간 높게 나올 수 있음 |
| 화훼·반려동물서비스 | 의료·건강 | 반려동물 미용·위탁, 화훼 서비스 (동물병원이 다수라고 가정) |
| 기타의복(의류신발) | 패션·쇼핑 | 실·원단(앱: 기타) |
| 기타개인용품 | 패션·쇼핑 | 혼례·장제례용품(앱: 기타) |
| 기타서비스 | 기타 | 부동산 수수료(앱: 주거·통신), 사진촬영(앱: 문화·여가), 응시료 |

- 부동산 수수료는 가계동향에서는 기타(생활비 밖), 앱에서는 주거·통신(고정비 아님 → 생활비 안)입니다. 10/22부터 가계동향의 주거·통신 생활비 몫은 고정비를 뺀 주택 수리·가사서비스뿐(생활비의 약 0.2%)이라, 앱의 주거·통신 변동 지출보다 조금 낮게 학습될 수 있습니다.
- 나머지 차이는 카테고리당 약 0.5%p 이하로 추정합니다.
- 발표·보고서에는 "공공용 통계 분류 단위의 한계로 일부 세부 항목이 인접 카테고리에 포함됨"으로 설명합니다.

## 5. 거래 분류 흐름

1. **규칙·사전**: 기타 대상(세탁·담배·복권·예식장·장례 등)과 다품목 가맹점(편의점·마트·종합몰) → 기타 또는 미분류로 바로 처리
2. **상가 사전 조회**: 상호명이 상가정보에서 한 업종으로 정해지면 결정표 카테고리로 확정
3. **ML 모델**: 상호명으로 10개 카테고리 중 하나 예측, 확신도가 높으면 확정
4. **LLM**: 확신도가 낮으면 검색·지도 정보로 보완 (기타도 선택 가능)
5. **사용자 확인**: 그래도 불명확하면 미분류로 두고 사용자가 선택
