## 4. 셋 다 지킬 규칙

| 규칙 | 이유 |
|---|---|
| 파일 맨 위에 `GET /api/csrf/` → 로그인 요청을 넣는다 | 로그인 안 하면 대부분 403 `not_authenticated` |
| API마다 **성공 1번 + 실패 1번 이상** (400 · 403 · 404 중 명세에 있는 것) | 실패 응답 모양도 명세(API_RULES.md)와 같은지 확인 |
| '요청 번호 ✔' API(10개)는 **같은 `Idempotency-Key`로 두 번** 보낸다 | 두 번 보내도 한 번만 저장되는지 확인. 새 키는 `{{$guid}}` |
| 명세와 다르면 **만든 사람에게 넘긴다** (테스트한 사람이 고치지 않는다) | 고치는 사람이 한 명이어야 안 꼬임 |
| 다 되면 표의 ☐ → ☑ | 진행 상황 공유 |
