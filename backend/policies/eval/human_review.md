# 사람 검수 20건 (LLM 채점 확인용)

채점자(gpt-6.2-sol)가 매긴 점수가 사람 판단과 얼마나 맞는지 본다. 질문마다 **사람 점수** 칸에 1~5점을 적는다 (5 = 기대대로, 3 = 절반쯤 맞음, 1 = 완전히 틀림).
채점자 점수와 근거를 보기 전에 먼저 매긴 뒤 비교하는 편이 좋다. 기준 설명은 `docs/agents/청년정책_평가서.md` 2절.

뽑은 방법: LLM 에이전트(현재 main) 결과에서 분야별 시험지 8분야 1개씩 + 낮은 점수 3개 + 사실 정확성 2점 이하 1개 + 사용자 평가셋 5개 + 요청 기록 3개 (무작위, seed 1118).
